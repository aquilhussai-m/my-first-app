# my-first-app
## Flow Studio

`flow-studio/index.html` खोलें — Google Flow (Veo) के लिए Prompt Generator, Shot Tracker और Script Builder।
सारा data browser के localStorage में रहता है (कोई server / API key नहीं)। Backup के लिए Shots tab → Export JSON।

## दुकान की वेबसाइट

`dukan/index.html` — कपड़ों की दुकान की वेबसाइट (हिंदी), हर कपड़े पर WhatsApp ऑर्डर बटन।
दुकान का नाम, WhatsApp नंबर और कपड़ों की लिस्ट file के नीचे `<script>` में `DUKAN` और `KAPDE` में बदलें।
